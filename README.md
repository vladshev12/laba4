# Лабораторная №4 Подсчет слов в тексте
## Реализованные функции
1. Чтение строки или текста
2. Очистка текста от основных занков препинания
3. Разбиение текста на слова
4. Подсчет количества повторений каждого слова с помощью словаря(`dict`)
5. Вывод результата в отсортированном виде по убыванию частоты в формате `слово -> количество`
